Getting started

  1. Install and open Utility. On first run you are asked about diagnostics and cloud backup. Both are off unless you switch them on.
  2. Go to Invoices and choose Import. Select one or many invoice files at once.
  3. Check what was read. Each invoice shows its lines, its totals, and whether it ties out to the total printed on the invoice.
  4. Resolve anything flagged. Warnings are advisory. A blocking failure keeps the export disabled until it is dealt with.
  5. Choose Export register. The file is written to your Utility folder, organised by month.

Files you can import

Invoices

PDF invoices with a text layer. Scanned images and further formats are being added.

Spreadsheets

Excel .xlsx, .xlsm and .csv can be opened and edited inside the app, with formulas.

Output

A single .xlsx register with three sheets. Existing exports are never overwritten.

The register format

The Sales Data sheet is produced in the standard register layout, one row per line item, with the invoice details repeated on every row:

ColumnContents
Invoice NoAs printed on the invoice
DateA real date, formatted dd-mm-yyyy
Party Name / GST NoThe buyer’s details
Product DescriptionThe line item
HSN CodeWritten as text, so leading zeros are preserved
QTY / UnitQuantity may be fractional. Unit is left blank rather than guessed
TaxableThe taxable value for the line
IGST / CGST / SGSTRate and amount. Only one of IGST or CGST+SGST applies
TOTALA live formula, so it recalculates if you edit a row

Two further sheets are included. Invoice Summary lists each invoice with its totals, round-off and the difference against the printed invoice total — this is the sheet to reconcile against. Import Log records which file produced which rows, and when.

Review and warnings

Utility distinguishes two kinds of finding. A warning is information — for example, a unit that the invoice never stated. A blocking failure means something does not add up, and the export stays disabled until it is resolved. This is deliberate: a loud failure is always better than a quiet mismatch in a register.

Lines with a quantity of zero are not carried into the register. Vendors often leave unordered items in the table, and those are not sales.

Where files are saved

By default everything goes to Downloads\Utility by Patience AI, with registers filed by month and edited spreadsheets kept separately. You can change the location in Settings. Exports are timestamped, so an earlier register is never overwritten.

Sharing on your office network

Turn on Local network to find other computers running Utility. Connecting requires a six-digit code shown on one machine and typed on the other. Connecting on its own grants nothing — you then choose whether that device may see the list, open records, or send records to you, and you can withdraw any of it later.

Backup and a second computer

Cloud backup is off unless you enable it. When on, your register data is compressed and encrypted on your own machine before it is uploaded, using a key derived from your password. Your password is never sent and the backup cannot be read without it. Signing in on another computer lets you restore that data there.

Updates

Updates download quietly in the background and install when you close the app, so an import in progress is never interrupted.

If Windows warns you

While our code-signing certificate is being issued, Windows may report an unrecognised publisher, or Smart App Control may block the installer. Choose More info → Run anyway. If Smart App Control blocks it outright, it can be turned off under Windows Security → App & browser control. This warning is about the certificate, not about the application.
